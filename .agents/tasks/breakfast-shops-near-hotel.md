## 請回覆這些資料

### 1. 覆驗上表四家

每家給我 `maps_place_details` 回傳的：
**name、formatted_address、location（lat/lng）、opening_hours（是否 24 小時）、business_status（是否仍營業）**。

⚠️ 若回傳的 `types` 含 `political` / `sublocality` / `locality` / `administrative_area_*`，
或名稱比查詢字串更短更泛化，代表被降級成町名，**請丟棄並用 `maps_search_places` 重查**。
（我這邊已經踩到兩次：查「セブンイレブン台東浅草橋1丁目店」得到町名「1 Chome 淺草橋」，
查麵包店得到町名「淺草橋」，都已剔除。）

### 2. 補齊可能遺漏的店

以 **飯店座標為中心、半徑 300 公尺**，用 `maps_search_places` 找出：

* 便利商店（`convenience_store`）
* 麵包店（`bakery`）
* 超市（`supermarket`）

排除上表四家，其餘一併附 place_id、座標、地址、營業時間。
**特別想知道有沒有早上很早開的麵包店**（例如 06:00–07:00 就開門），
因為 Day 2 迪士尼日 06:25 就要吃早餐。

### 3. 最重要：實際步行路線與繞路成本

對每一家店，算出**步行**（不是直線）：

| 欄位 | 說明 |
| :-- | :-- |
| A | JR 西口 ➜ 該店 步行距離與時間 |
| B | 該店 ➜ 海茵娜酒店 步行距離與時間 |
| C | JR 西口 ➜ 海茵娜酒店 直接走的距離與時間（基準） |
| **繞路成本** | **(A + B) − C**，單位公尺與分鐘 |

然後**同一套再算一次，起點換成都營淺草線 A1 出口**。

### 4. 動線註記

* 該店在**江戶通り的哪一側**？走過去要不要**過馬路**？（帶長輩小孩，少過一次馬路差很多）
* 是否需要**跨過神田川**？
* 路上有沒有**階梯**？

## 輸出格式

用一張表把四家（加上新找到的）依「繞路成本」由小到大排序，並直接回答：

* **JR 西口出站時最順路的是哪一家？**
* **都營 A1 出口出站時最順路的是哪一家？**

⚠️ 查不到就標「查無」，**不要用附近的店或町名頂替**。
