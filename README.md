## **💡 新手交通與搭車重要提醒**

> * 認顏色與月台比認日文快： 東京的 JR 線路都有專屬代表色。在車站搭車時，請認明「月台編號」與「車輛顏色」（例如：中央・總武線 \= 黃色列車、山手線 \= 綠色列車）。這比辨識複雜的日文漢字更直覺，最不容易坐錯方向。  
> * 下載 App 協同輔助： 手機請先下載「乘車案內」App，或在進站時搭配「Google Maps」確認即時的月台與發車時間。
